# 출처 — 실제 상품 공시 문서 5종

각 은행/카드사/보험사가 실제로 배포 중인 PDF 상품설명서·표준약관을 원문 그대로 다운로드해 텍스트로 변환했습니다. 재작성·재요약 없음(PDF→텍스트 변환 과정에서 레이아웃 정보만 소실).

| 상품유형 | 폴더 | 발행 기관 | 문서명 |
|---|---|---|---|
| 예금 | `예금/` | 신한은행 | 쏠편한 정기예금 상품설명서 |
| 적금 | `적금/` | 신한은행 | 청년 처음적금 상품설명서 |
| 신용대출 | `신용대출/` | 신한은행 | 가계대출 상품설명서(신용대출 포함) |
| 신용카드 | `신용카드/` | 부산은행(여신금융협회 표준약관 준용) | 신용카드 개인회원 표준약관 |
| 보장성보험 | `보장성보험/` | KB라이프생명 | (표준형/해약환급금 일부지급형) 무배당 함께크는 종신보험 상품설명서 |

각 하위 폴더의 `SOURCE.md`에 개별 URL·수집일·방법·한계를 기록했습니다.

## 공통 수집 방법

1. 웹 검색(Tavily)으로 각 상품유형별 공개 PDF 상품설명서/표준약관을 탐색.
2. `curl`로 원본 PDF를 직접 다운로드(브라우저 User-Agent 사용, 별도 인증 불필요한 공개 게시 파일만 선택).
3. Python `pypdf`로 페이지별 텍스트를 추출, 페이지 구분(`--- page N ---`)만 삽입하고 본문은 그대로 보존.

## 공통 한계

- PDF 텍스트 추출 특성상 표(이자율 표, 우대조건 표 등)의 행렬 구조가 줄바꿈 기준 평문으로 풀려 원래 표 형태와 다르게 보일 수 있음 — 텍스트 내용 자체는 원문과 동일.
- 상품설명서는 발행 시점 기준 최신 조건(금리·한도 등)을 반영한 것으로, 실제 계약 시점과는 조건이 달라질 수 있음(원문에도 동일한 경고 문구 포함).
- 5종 모두 각 사가 자사 홈페이지에 공개 게시한 문서이며, 파인(FINE)·은행연합회 소비자포털에서 직접 개별 PDF를 원클릭으로 받는 경로는 찾지 못해 각 발행사 홈페이지 원문을 사용함. 파인·은행연합회는 상품 비교·금리 조회 UI 중심이라 개별 상품설명서 원문 PDF를 직접 서빙하지 않는 경우가 많았음.
